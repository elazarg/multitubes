# Games and model checking

This client isolates the information carried by nested least and greatest fixed points. A
two-variable mutual-copy system has the same local exact equations under two opposite priority
nestings: least-outside/greatest-inside selects the bottom solution, while the reverse nesting
selects the top solution. Both are exact sections of the same transport graph.

Priority and parity data therefore sit above local exact, lax, or oplax edge constraints. Game
semantics, determinacy, strategy extraction, and parity acceptance remain domain-specific.
