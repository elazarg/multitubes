# Riccati equations and filtering

Directed transport can model a graph of modes, sensor configurations, or information states whose
fibers are positive semidefinite matrices and whose edges carry Riccati, prediction, observation,
or covariance-update maps. Exact sections describe consistent covariance families; lax and oplax
sections describe one-sided covariance or information bounds.

The Löwner order is generally not a lattice, so this domain uses transport results based on order,
monotonicity, and composition without assuming lattice joins. Cone geometry, contraction, and
filtering semantics are supplied by matrix analysis.
