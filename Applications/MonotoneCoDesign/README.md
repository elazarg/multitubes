# Monotone co-design

Directed transport can model networks of functionality and resource posets linked by monotone
feasibility relations. A relation may be lifted to powersets by existential image and universal
residual, or represented directly by relation-labelled transport. Sections then express feasible
assignments and interface constraints.

Interconnection semantics, implementation spaces, continuity assumptions, and Pareto-front
representations supply the co-design structure.
