# Monotone co-design

This client treats component feasibility as a relation between ordered interfaces. Relations
compose natively along typed graph walks, while existential image embeds the same semantics into
ordinary directed transport on powersets. Native feasible assignments become oplax sections of
that transport, so the generic walk calculus propagates local feasibility through a network.

The monotone specialization records the co-design convention that requiring less functionality
or allowing more resources preserves feasibility. Serial composition preserves this law, and
feasible resource sets are upward closed. The order relation is the serial identity, so every
nonempty network path is again a monotone feasibility problem. Pareto-front representations,
recursive feedback, and Scott-continuity assumptions remain separate from this small semantic
client.
