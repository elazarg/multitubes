# Conic finance with transaction costs

This client places portfolio increments on the edges of a deterministic market graph. Native
transaction relations compose along paths by Minkowski addition, while existential image embeds
the same semantics into transport on powersets. Serial composition preserves convexity, whereas
union over alternative paths can require a separate convexification step.

Cone separation, probability, adaptedness, stochastic integration, measurable selection, and the
financial no-arbitrage interpretation remain domain-specific.
