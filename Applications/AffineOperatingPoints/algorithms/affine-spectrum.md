# Testing a prescribed max-affine eigenvalue

Given a rational level $\lambda$, decide whether a finite real vector satisfies $F(x)=x+\lambda$ for a max-affine graph. Two rational linear programs of linear size suffice, with $O(nm)$ additional rational operations for $n$ vertices and $m$ affine branches. An unsuccessful relaxation gives a normalized gain-flow certificate. A feasible relaxation without an eigenvector gives a different certificate, consisting of a potential and a recession direction. Both can be checked without solving an LP.

Each vertex has a nonempty set of incoming branches. Branch $e:u\to v$ contributes $a_e x_u+b_e$ to $F_v$, where $a_e\ge 0$ and $b_e$ is rational. A finite floor on an edge contributes a separate zero-gain branch. An absent floor contributes no row. The max-plus timing application has unit gains and floorless labels. At mixed gains, the eigen-equation is a one-step offset equation, and the timing application's linear-orbit and throughput conclusions require additive homogeneity. [Firing operator and its additive hypothesis](../../DiscreteEventSystems/DiscreteEventSystems/Synchronization.lean) · [Genuine branches](../../../Maths/Multitubes/MaxAffine/Duality.lean)

## The two linear programs

Write $d_e=b_e-\lambda$, $T_v(x)=F_v(x)-\lambda$, and
$$
P=\{x\in\mathbb R^n: x_v\ge a_e x_u+d_e\text{ on every branch }e:u\to v\}.
$$
Let $G_+$ consist of the branches with strictly positive gain. The gain of a directed walk is the product of its gains. Call a cycle *contracting* when its gain is below one and *expansive* when its gain exceeds one.

1. Let $B$ be the vertices that can reach an expansive cycle in $G_+$. Maximize $\sum_{v\in B}x_v$ over $P$. If infeasible, return a normalized gain-flow certificate. Otherwise let $U$ be any optimizer. When $B$ is empty, use any feasible $U$.
2. Form the tight graph of positive branches that are equalities at $U$. Let $J$ be all vertices on a directed cycle in this graph. In $G_+$, start from $J$, all zero-gain branch targets, and all vertices on contracting cycles. If some vertex is unreachable, return $U$ and a downward recession direction. If all vertices are reached, minimize $\sum_v x_v$ over $P$ with $x\le U$ and $x_j=U_j$ for $j\in J$. The result is an eigenvector.

The reachability test is equivalent to requiring one of the three kinds of starting vertices in each source strongly connected component of $G_+$. The positive graph and the contracting-cycle search can be reused across levels. The tight graph and its cycle vertices can change with the level. The condition at the bottom of the relaxation set in the library freezes targets of optimal certificates. Here tight cycles freeze coordinates at any prescribed level, and the first LP chooses $U$ so that the resulting reachability condition is necessary as well as sufficient. ## Correctness

**Upper bounds.** Composing branch inequalities around a cycle based at $v$ gives $x_v\ge A x_v+D$, where $A$ is its gain and $D$ its composed shift. For $A>1$ this caps $x_v$ above. A positive-gain path to such a cycle propagates the cap backwards, so all coordinates in $B$ have finite maxima when $P$ is nonempty. Each maximum is attained by linear programming. The pointwise maximum of two feasible vectors is feasible, since each $a_e\ge 0$. Taking the maximum of finitely many individual maximizers shows that the first LP attains every finite coordinate maximum simultaneously.

For the converse description of $B$, take the complement $W$. It has no expansive cycle and no positive arc from $W$ into $B$. For $v\in W$, let $p_v$ be the largest product on any walk inside $W$ ending at $v$, including the empty walk of product one. Deleting cycles of product at most one shows that these products have finite maxima on paths. Set $p_v=0$ on $B$. Then $p_v\ge a_e p_u$ for every branch, so $x+tp$ stays in $P$ for $t\ge0$ and every coordinate in $W$ is unbounded above.

**Necessity of coverage.** Suppose $T(y)=y$. For each vertex choose a branch at equality at $y$ and trace the chosen predecessors backwards. The trace meets a constant branch or reaches a positive cycle. A constant target and a contracting cycle are already among the starting vertices. On a cycle with gain one, its composed shift must be zero. For a feasible vector the weighted sum of cycle slacks is then zero, with strictly positive weights, so every edge of that cycle is tight at $U$. On an expansive cycle, composition gives a universal cap at each cycle vertex and $y$ attains that cap. Since those vertices belong to $B$, $U$ also attains their caps and the cycle is again tight. In each case the traced path goes from a starting vertex to the original vertex.

**Witness construction.** Every constant branch gives an absolute lower bound. A contracting cycle's composed inequality gives an absolute lower bound $D/(1-A)$. Each pinned coordinate is already bounded below. These lower bounds propagate forward along positive paths, so coverage bounds the second feasible region below. The region contains $U$, is closed, and has the coordinate upper bounds $U$. Its pointwise minimum of any two vectors is feasible: in each row select the vector furnishing the target minimum and use monotonicity at the source. Therefore a minimizer of the sum is its least vector.

If $x$ lies in that region, feasibility and monotonicity give $T(T(x))\le T(x)\le x\le U$. For each vertex $j$ on a tight cycle, one cycle branch into $j$ is tight at $U$ and both its endpoints are pinned. It forces $T_j(x)\ge U_j$, hence $T_j(x)=U_j$. Thus $T(x)$ lies in the same region. Applying this to its least vector gives $T(x)=x$. This is the finite counterpart of the library's decreasing iteration from a bounded upper potential. [Bound propagation and monotone convergence](../../../Maths/Multitubes/MaxAffine/ReachableLowerBounds.lean)

**An optional cap.** The algorithm above uses no numerical box. A variant may replace the first LP by maximizing the sum of all coordinates over $P\cap[-C,C]^n$. To compute a safe $C$, clear denominators in each row and let $H\ge 1$ bound the absolute integer coefficients and right-hand sides. Use $C=(n+1)!H^{n+1}$. The box contains a feasible potential whenever $P$ is nonempty, and some eigenvector whenever one exists. For the second claim fix an attained branch at each coordinate of any real eigenvector and include its reverse inequality. Add a scalar $t\ge0$ with $-t\le x_v\le t$, and minimize $t$. The optimum has a vertex in its compact optimal face. Cramer's rule bounds every coordinate using $n+1$ independent tight rows. The same argument without the selected equalities proves the feasibility claim. The maximizing potential in the box dominates a bounded witness. The active-cycle proof above now applies, and the second LP uses its usual constraints without the artificial lower box. The bit length of the cap is $O(n(\log H+\log(n+1)))$.

## Graph passes and certificates

To mark descendants of expansive cycles in a positive-gain graph, start every vertex at product one. In a synchronous round, raise each label to the maximum of its old label and the old predecessor labels multiplied by their incoming gains. After $k$ rounds a label is the best product of a walk of length at most $k$. An improvement on round $n$ uses a length-$n$ walk from which no cycle of gain at most one can be removed while preserving or improving the product. The walk therefore contains an expansive cycle. Every expansive cycle has an improvement at one of its vertices in round $n$, since unchanged labels on the cycle would yield $p_v\ge A p_v$ for some $p_v\ge 1$ and $A>1$. Mark the descendants of these improvements. Reverse all arcs to compute $B$. Keep the original arc directions and use reciprocal gains to mark descendants of contracting cycles. Strongly connected components identify $J$ in linear graph time. The product passes use $O(nm)$ rational operations, with $O(nL)$ bits per path product when a gain has at most $L$ bits. Multiplicative Bellman–Ford and cycle bounds for monotone two-variable inequalities are established operations. [Dadush, Koh, Natura and Végh, §§2.2 and 4](https://eprints.lse.ac.uk/117202/1/newton_002_.pdf)

A successful certificate consists of the eigenvector itself. Check every branch inequality and one equality per vertex. For an infeasible relaxation, check nonnegative weights $w_e$ of total mass one with zero weighted row vector and $\sum_e w_ed_e>0$. A weighted sum of all branch inequalities would then imply $0>0$. [Normalized threshold duality](../../../Maths/Multitubes/MaxAffine/Duality.lean)

For a feasible relaxation with failed coverage, the certificate is $U$ and a nonzero vector $r\ge 0$ with $r_v\le a_e r_u$ on every branch and $r_j=0$ on $J$. It proves that the second feasible region contains $U-tr$ for every $t\ge0$. Such a direction can be constructed on the uncovered set $R$. No constant target or contracting cycle lies in $R$, and no positive branch comes into $R$ from its complement. In the graph on $R$ with directions reversed and gains reciprocated, take the largest path product at each vertex, including the empty path. Every cycle in that graph has gain at most one. Extend the labels by zero off $R$. They give the required direction.

The verifier checks $U\in P$ and recomputes $B$ in both the full and tight graphs. Equality of the two sets certifies simultaneous maximization: a tight path to a tight expansive cycle composes to a cap with equality at $U$. An optimizer always has this property. Otherwise the walk-product construction for the complement of the tight graph's bounded set would provide a nonnegative direction increasing a coordinate in $B$, satisfying every tight row. A small enough step preserves the finitely many strict rows as well, contradicting the optimum. This test, the tight-cycle computation, and the recession inequalities verify the obstruction without trusting the solver. Verification takes $O(nm)$ rational operations in the worst case.

## Example and prior methods

For $(F_0,F_1)=(\max(2x_0,3x_0),\max(2x_0+1/2,3x_1))$, the first equation requires $x_0=\min(\lambda,\lambda/2)$. The second admits a solution exactly when $2x_0+1/2\le 3\lambda/2$, since $x_1\le\lambda/2$ and choosing its bound makes the self-loop tight. The spectrum is $(-\infty,-1]\cup[1,\infty)$. Every level has a feasible relaxation, and at every level the all-$-\infty$ vector is the least extended-real fixed point. At $\lambda=-1$ the solver returns $(-1,-1/2)$. At zero it returns $U=(-1/4,0)$ and $r=(1,0)$. The sink is pinned, but both root loops are slack at the upstream cap and the root admits the certified descent. A star of these gadgets realizes any finite union of rational closed intervals and rays. [Inverse spectrum construction](inverse-spectrum.md)

Least-fixed-point LP methods for abstract interpretation already optimize the sum of variables where a finite least solution exists. Gawlitza et al. also address infinite values by working over the extended reals. The two levels above have the same extended-real least vector and different answers to finite existence. Adjé, Gaubert and Goubault give the sum-minimization formula for nonexpansive finite affine maxima under a smallest-real-fixed-point assumption. The algorithm here first locates pins that make the second minimization valid and handles expansive gains and rays of feasible points. [Gawlitza et al., §5.2](https://perso.univ-perp.fr/assale.adje/upload/1-s2.0-S0747717111002513-main.pdf) · [Adjé, Gaubert and Goubault, Proposition 15 in the MTNS version](https://www.lix.polytechnique.fr/~goubault/papers/finalmtns.pdf)

Discounted Bellman LPs gain uniqueness from contraction. Bertsekas's semicontractive affine-monotonic model admits noncontractive policies, with the finite-state results starting from at least one contractive policy. All branches in the example are positive and every policy contains an expansive root loop. The finite-existence reduction here allows that case, and uses the single-predecessor structure of the branches. Dadush et al. solve general two-variable-per-inequality optimization in strongly polynomial time. Applying it to these two LPs proves a strongly polynomial algorithm for the rational decision and witness problem. [Bertsekas, Assumption 1](https://arxiv.org/html/1608.01393v2) · [Dadush, Koh, Natura, Olver and Végh](https://doi.org/10.1145/3618260.3649764)

## Run and verify

Run `python3 affine_spectrum.py` with `z3-solver` installed for the exact LP solve. Use `--input problem.json` for a custom instance. Branch arrays give tail, head, gain and unrelaxed offset. Vertices start at zero. Use integer JSON numbers or strings such as `"1/2"` for rationals. Add a zero-gain row for each finite floor. This input tests level zero in the example.

```json
{
  "vertices": 2,
  "level": 0,
  "branches": [[0, 0, 2, 0], [0, 0, 3, 0], [0, 1, 2, "1/2"], [1, 1, 3, 0]]
}
```

The output JSON is itself the certificate. Replay it with `python3 affine_spectrum.py --input problem.json --check certificate.json` using Python's standard library. An infeasible relaxation triggers a separate rational feasibility call in the prototype to extract normalized multipliers. A primal-dual LP backend can return its own infeasibility certificate. The prototype uses Z3 rational linear arithmetic. The strongly polynomial bound applies with the cited specialized optimizer. The linked Lean results supply the starting theorems. The two-LP reduction and certificate checker have the written proofs above and executable checks.

The independent test enumerates active branch choices and uses exact Fourier–Motzkin feasibility for each choice on small instances. It checks 480 seeded instances with mixed gains, parallel branches and constants, plus targeted unit-cycle, expansive-cap and contracting-cycle cases. The optional benchmark uses star graphs up to 257 vertices and 769 branches, with at least $2^{256}$ policy combinations on the largest instance. Verification is included in those timings.
